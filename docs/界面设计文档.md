## 1. 设计目标与参考

### 1.1 设计目标

打造**专业、清爽、高效**的中国联通企业内部会议室预约体验：

- 3 秒内看懂当日各会议室占用情况
- 5 秒内完成一次预约（从点击空白格到提交）
- 管理后台信息密度适中，操作路径短
- 视觉风格现代，融入**中国联通品牌红色**，体现企业识别度

### 1.2 行业参考项目

| 参考产品 | 借鉴点 | 链接 |
|----------|--------|------|
| **Cal.com** | 极简黑白主色、大圆角卡片、时段选择清晰、预约流程短 | [cal.com](https://cal.com) |
| **Robin** | 会议室资源视图、实时占用状态、按容量/设备筛选 | [robinpowered.com](https://robinpowered.com) |
| **Google Calendar（资源日程）** | 甘特式时间轴、色块区分预约、Sticky 表头 | — |
| **Notion Calendar** | 留白充足、字体层级清晰、低干扰配色 | — |
| **shadcn Room Booking Block** | 楼层/房间列表 + 时段网格组合布局 | [shadcn.io/blocks/calendar-room-booking](https://www.shadcn.io/blocks/calendar-room-booking) |
| **Linear** | 侧边栏导航、精致图标、暗色可选、操作反馈即时 | [linear.app](https://linear.app) |
| **飞书日历 / 钉钉日程** | 国内企业用户熟悉的日程交互习惯 | — |

### 1.3 设计风格定位

```
中国联通品牌风 + 现代 SaaS 效率感
─────────────────────────────────
✓ 主色采用中国联通「中国红」，辅色「水墨黑」
✓ 大量留白，信息分组清晰
✓ 用色彩表达「状态」，红色仅作品牌强调与关键操作
✓ 日程网格为核心视觉焦点
✓ 卡片化布局，轻阴影 + 大圆角
✗ 避免渐变堆砌、过多边框、密集表格线
```

### 1.4 品牌色彩来源

| 色彩 | 说明 | 参考色值 |
|------|------|----------|
| **中国红（主色）** | 2020 品牌焕新后的「新科技红」，更明亮年轻 | `#E60012` |
| **中国红 Hover** | 主色加深，用于按钮悬停 | `#C9000F` |
| **中国红浅底** | 选中态、我的预约、推荐卡片背景 | `#FFF1F0` |
| **水墨黑（辅色）** | 联通品牌辅助色，用于标题、顶栏文字 | `#1A1A1A` |
| **墨灰** | 次要文字、边框 | `#64748B` |

## 2. 设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **一眼看清** | 日程页打开即展示当日占用，减少点击 | 顶部摘要条：「今日 3 间会议室 · 12 个时段已预约」 |
| **就近操作** | 在网格上直接预约，减少页面跳转 | 点击空白格 → 侧边抽屉表单 |
| **状态可辨** | 空闲/已约/我的预约/已过期 四态颜色区分 | 绿/灰/联通红/浅灰斜纹 |
| **反馈即时** | 每个操作有 Toast / 加载 / 成功动画 | 预约成功轻量 Confetti 或 ✓ 动画 |
| **管理高效** | 后台表格 + 抽屉编辑，批量操作显眼 | 用户管理顶部固定操作栏 |
| **智能推荐** | 选时段即推荐空闲会议室，无则明确引导 | 「暂时没有空闲会议室，请修改其他时间」 |

| 状态 | 背景色 | 边框/文字 | 说明 |

| 状态 | 颜色 |
|------|------|
| 可用 | 绿色 `#10B981` |

| 推荐 | 橙色 `#FAAD14` + 「推荐」Tag |

| 层级 | 字号 | 字重 | 用途 |

| H1 | 24px | 600 | 页面标题 |

| Token | 值 | 用途 |
|-------|-----|------|

| 层级 | 值 | 用途 |
|------|-----|------|
| Shadow SM | `0 1px 2px rgba(15,23,42,0.05)` | 卡片默认 |

### 3.5 图标

- 使用 **Ant Design Icons** + **Lucide React**（线性图标，24px 默认）
- 导航图标统一 20px，操作按钮 16px
- 会议室行左侧可选设备图标：📽 投影、📹 视频、👥 容量

## 6. 核心组件规范

### 6.1 ScheduleGrid（日程网格）

自研核心组件，视觉参考 Google Calendar Resource View。

| 属性 | 类型 | 说明 |
|------|------|------|
| `date` | string | 当前日期 |
| `rooms` | Room[] | 会议室列表（纵轴） |
| `bookings` | Booking[] | 预约数据 |
| `slotMinutes` | number | 30 |
| `startTime` / `endTime` | string | 08:00 / 20:00 |
| `currentUserId` | number | 区分我的/他人预约 |
| `onSlotClick` | fn | 点击空白格 |
| `onBookingClick` | fn | 点击预约块 |
| `onSlotDrag` | fn | 拖选时段（P1） |

**渲染规则：**

1. 预约块 `left = (startIndex × cellWidth)px`，`width = (slotCount × cellWidth)px`
2. 同一行多个预约不重叠（后端保证）
3. 当前时间线：`now()` 在 08:00–20:00 内时渲染红色竖线
4. 过期时段（当天已过）：单元格加 45° 浅灰斜纹

## 7. 交互与动效

### 7.1 动效原则

- **轻量**：过渡 150–250ms，ease-out
- **有目的**：动效服务于反馈，不做纯装饰
- **可关闭**：尊重 `prefers-reduced-motion`

### 7.2 关键动效

| 场景 | 动效 | 时长 |
|------|------|------|
| 页面切换 | 内容区 fade-in | 200ms |
| Drawer 打开 | 右侧滑入 | 250ms |
| Modal 打开 | 缩放 0.95→1 + fade | 200ms |
| 预约成功 | Toast 滑入 + ✓ 图标 | 300ms |
| 网格刷新 | 预约块 fade-in | 150ms |
| 冲突提示 | 对应格红色闪烁 2 次 | 400ms |
| 按钮点击 | scale 0.98 | 100ms |
| 表格行 hover | 背景色过渡 | 150ms |

### 7.3 加载状态

| 场景 | 方案 |
|------|------|
| 日程网格加载 | Skeleton 骨架屏（行 × 列灰色块） |
| 表格加载 | Ant Design Table loading |
| 提交预约 | 按钮 loading + 禁用 |
| 批量导入 | Upload progress 进度条 |

### 7.4 反馈消息

| 类型 | 组件 | 示例 |
|------|------|------|
| 成功 | `message.success` | 「预约成功」「导入完成：48 条成功」 |
| 错误 | `message.error` | 「该时段已被预约」「用户名已存在」 |
| 警告 | `message.warning` | 「该会议室已停用」 |
| 确认 | `Modal.confirm` | 「确定取消此预约？」 |
